# Centrifugo 从入门到精通：一本书搞定实时消息推送

> **适用版本**: Centrifugo v6.x（开源版）  
> **读者对象**: 有基础开发能力，但完全不了解 Centrifugo 的开发者  
> **目标**: 从 0 概念到能独立设计和运维 Centrifugo 实时消息系统

---

## 📖 这本书的结构

本书按照 **「新手 → 熟悉 → 精通」** 三个阶段组织，每个阶段有明确的学习目标：

### 🟢 新手阶段：能跑起来，能推消息

| 章节 | 内容 | 预计阅读 |
|------|------|----------|
| [第1章 - Centrifugo 是什么](01-what-is-centrifugo.md) | 项目定位、架构总览、适用场景 | 15 分钟 |
| [第2章 - 快速开始](02-quick-start.md) | 安装、配置、第一条实时消息 | 30 分钟 |
| [第3章 - 核心概念](03-core-concepts.md) | 频道、发布、订阅、在线状态、历史消息 | 20 分钟 |

### 🟡 熟悉阶段：能用于真实业务

| 章节 | 内容 | 预计阅读 |
|------|------|----------|
| [第4章 - 认证与鉴权](04-authentication.md) | JWT 认证、代理认证、匿名连接 | 25 分钟 |
| [第5章 - 服务端 API](05-server-api.md) | HTTP API 全接口 curl 示例 | 30 分钟 |
| [第6章 - 客户端 SDK](06-client-sdk.md) | JavaScript/移动端 SDK 使用 | 25 分钟 |
| [第7章 - 频道与命名空间](07-channel-config.md) | 命名空间、权限策略、频道选项 | 20 分钟 |

### 🔴 精通阶段：能设计架构、排查问题、运维大规模系统

| 章节 | 内容 | 预计阅读 |
|------|------|----------|
| [第8章 - 水平扩展](08-scaling.md) | Redis 引擎、NATS Broker、多节点部署 | 25 分钟 |
| [第9章 - 代理机制](09-proxy.md) | Connect/Subscribe/Publish/RPC 代理 | 25 分钟 |
| [第10章 - 消息队列消费者](10-consumers.md) | Kafka、PostgreSQL Outbox、CDC 模式 | 25 分钟 |
| [第11章 - 管理与监控](11-admin-monitoring.md) | Admin UI、Prometheus、Grafana | 20 分钟 |
| [第12章 - 生产部署](12-production.md) | TLS、安全加固、Docker/K8s 部署 | 25 分钟 |
| [第13章 - PRO 版 vs 开源版](13-pro-vs-oss.md) | 功能对比、定价分析、选型建议 | 15 分钟 |
| [第14章 - 常见问题与踩坑指南](14-troubleshooting.md) | 各阶段常见坑、项目周期变化 | 20 分钟 |
| [第15章 - 进阶模式与最佳实践](15-advanced.md) | 架构模式、性能优化、大规模设计 | 30 分钟 |

## 💡 如何使用这本书

1. **如果你赶时间**：只看第 1-3 章，30 分钟内能跑通 demo
2. **如果你要上业务**：看第 1-7 章，能独立接入真实项目
3. **如果你要负责运维**：全部看完，特别关注第 8、11、12、14 章
4. **如果你在选型**：先看第 1 章和第 13 章（PRO 版对比）

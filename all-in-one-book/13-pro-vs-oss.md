## 13.3 关键 PRO 功能详解

### 推送通知 API

PRO 版集成了移动推送通知，可以统一管理 FCM/APNs/HMS：

```
价值：不需要单独搭建推送服务
     用同一套 API 管理实时消息和离线推送
     与频道订阅系统整合
```

### 操作速率限制

```
价值：防止恶意客户端或有 Bug 的客户端
     发起过多的订阅/发布/RPC 请求
     保护后端代理服务不被压垮
```

### ClickHouse 分析

```
价值：将实时消息数据导入 ClickHouse
     生成业务分析报表
     追踪消息投递状态和系统健康趋势
```

### JWT 撤销

```
价值：在 Token 过期前主动失效
     用户修改密码后立即使旧 Token 失效
     安全事件时紧急撤销 Token
```

### 频道模式 (Channel Patterns)

```
价值：像 HTTP 路由一样定义频道配置
     例如：chat/{room_id} 匹配所有聊天室
     简化大量频道的配置管理
```

## 13.4 定价分析

### 开源版成本

```
软件费用：$0
基础设施成本：
  - 服务器：$50-500/月（取决于规模）
  - Redis：$20-200/月
  - 运维人力：自行负担

总成本 = 基础设施 + 运维人力
```

### PRO 版成本

```
许可证费用：基于公司规模和用例的固定费用
           需要联系 Centrifugal Labs 获取报价
           不按连接数或消息数计费

包含：
  - 1 年许可 + 优先支持
  - 所有 PRO 功能
  - 技术咨询

总成本 = 许可证 + 基础设施 + （较少的）运维人力
```

## 13.5 什么时候值得买 PRO？

### ✅ 推荐购买 PRO 的场景

```
1. 需要推送通知整合
   → 不买 PRO：你需要自己搭建推送服务（成本可能超过 PRO 授权费）

2. 需要 ClickHouse 分析
   → 对消息数据有分析需求的企业

3. 安全合规要求高
   → 需要 JWT 撤销、速率限制、用户封禁等功能

4. 大规模部署（>10万连接）
   → PRO 的性能优化能显著节省服务器成本

5. 需要 Admin SSO
   → 企业安全策略要求统一认证

6. 运维团队小
   → 优先技术支持能减少排查问题的时间
```

### ❌ 不需要买 PRO 的场景

```
1. 个人项目或学习
   → 开源版功能完全足够

2. 初创公司早期
   → 先用开源版验证产品，再考虑升级

3. 简单的实时通知
   → 开源版的 PUB/SUB + 历史消息足够

4. 小规模应用（<1万连接）
   → 开源版性能完全足够

5. 只需要消息转发
   → 开源版的核心功能没有限制
```

## 13.6 开源版的替代方案

对于 PRO 版才有的功能，开源版可以这样替代：

| PRO 功能 | 开源版替代方案 |
|---------|--------------|
| 推送通知 | 独立使用 Firebase/OneSignal |
| JWT 撤销 | 缩短 Token 过期时间 + Refresh |
| 速率限制 | 在 Nginx/API Gateway 层做 |
| 用户封禁 | 通过 disconnect API + 代理拦截 |
| ClickHouse 分析 | 自己从 Prometheus 指标分析 |
| Admin SSO | 通过反向代理实现 |
| 连接查询 | 通过 presence API 间接查询 |
